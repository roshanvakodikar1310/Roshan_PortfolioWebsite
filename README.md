# Roshan Vakodikar — Personal Portfolio

A responsive portfolio made with **plain HTML, CSS and vanilla JavaScript**. No React, Vite, Node.js, backend, or build step is required.

## Run it
1. Extract the ZIP folder.
2. Open `index.html` in Chrome, Edge, Firefox, or another browser.
3. Edit the content in `index.html` and design in `style.css` as needed.

## Important personalisation before publishing
- Replace `roshan@example.com` in `index.html` and `script.js` with your real email address.
- Replace the generic GitHub and LinkedIn URLs in the hero section with your own profile links.
- Add your real resume PDF to the project and link it from the page if you want a resume-download button.
- The project artwork is made with HTML/CSS mockups; replace it with actual screenshots or live project links when ready.
- Confirm that all skills and project descriptions accurately reflect your own work before publishing.

## Files
- `index.html` — all page sections and content
- `style.css` — responsive styling, layout, and animations
- `script.js` — mobile navigation, scroll progress, reveal effects, and email form behaviour

## Contact form note
The form uses `mailto:` and opens the visitor's default email app. It does not send or store submissions on a server.
